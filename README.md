## Projetos pessoais

### [llm-extraction-eval](https://github.com/davibarbosabdj/llm-extraction-eval)

Como saber se um extrator de informação com LLM é bom o bastante para ir para produção? Este projeto monta o método de avaliação: gabarito, métricas por campo, medida de alucinação, comparação com linhas de base sem LLM e um portão de qualidade que decide o que passa sem revisão humana.

- Usa **laudos sintéticos** (nenhum dado real) com armadilhas como caixas de seleção, histórico, negação e ruído de OCR.
- Nas linhas de base, regras escritas à mão acertam 95% dos laudos em formatos conhecidos e 0% em formatos inéditos. É o argumento para medir o LLM justamente onde as regras falham.
- Python, pytest, 50 testes. A etapa com Azure OpenAI está em andamento.
